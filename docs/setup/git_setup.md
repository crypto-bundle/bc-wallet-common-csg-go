# Настройка окружения для работы с Git

---
**Цель**: Настроить локальное окружение для работы с проектом
**Категория правил**: Настройка среды
**Краткое содержание:** SSH/GPG ключи, настройки shell и Git
---
Для работы над проектами в репозиториия GreenPayment https://github.com/Greenpayment/,
необходимо подготовить свое рабочее окружение. Если кратко необходимо:
- Изменить настройки командной оболочки(`shell` - `bash`, `zsh`, `fish`) для языка разработки Go
- Cоздать отдельный ssh-ключ для работы с github через ssh
- Создать отдельный GPG-ключ для подписи коммитов и тегов
- Настроить локально Git для работы с приватными репозиториями
