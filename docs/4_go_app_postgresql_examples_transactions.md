# Слой данных. Работа с PostgreSQL. Механизм работы с транзакциями

## Введение

Данный документ содержить в себе рекомендации и правила работы с библиотекой `bc-wallet-common-lib-postres` -
https://github.com/crypto-bundle/bc-wallet-common-lib-postgres, входящей в базовый тулкит проекта. 
В частности, ниже ниже будет рассказано о способах работы с тразакционным стейтментом.

Управление транзакционным контекстом осуществляется с помощью функций:
- `BeginTxWithRollbackOnError` - рекомендуемая для 99% случаев. Стартует транзакционный стейтмент,
  и автоматически делает `rollback`, если в процессе испонения запросов произошла ошибка. 
  Данная функция рекомендуется как **основная к применению**.
- `BeginContextualTxStatement`
- `CommitContextualTxStatement`
- `RollbackContextualTxStatement`

Использование транзакцонного контеста возможно через функции:
- `TryWithTransaction`
- `MustWithTransaction`

Основным принципом работы вышеуказанных функций является сохранение и 
паредача экземпляра транзакционного стейтмента через контекст - `ctx context.Context`.
Функции управления транзакциями сохраняют переменную с экземпляром _транзакционного стейтмента_
в контекст, который позже используется другими функциям объявленными в пакете и сервис-компонентах
представляющих [слой данных](./4_go_app_data_layer.md) для базы данных _PostgreSQL_.

Другим важным моментом является использование концепции замыкания и анонимных функция при написании
какой-либо бизнес-логики, а так же функций слоя данных.
