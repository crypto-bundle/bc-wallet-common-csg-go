# Форматирование ошибок. Коды ошибок. Правила написания кода

## Введение

В данном документе описаны правила и рекомендации по организации кода приложения в 
контексте _форматирования ошибок_. Так же в данном документе описаны правила описания и формирования
так называемых _**кодов-ошибок**_.

Данная документация описывает как пользоваться библиотеками форматирования
ошибок входящими в базовый тулкит проекта. Речь пойдет про:
- Принципы проверки ошибок
- Использование библиотек:
  - https://github.com/crypto-bundle/bc-wallet-common-lib-tinyerrors
  - https://github.com/crypto-bundle/bc-wallet-common-lib-errors

## Правила

- Ошибки которые должны передаваться вне приложения должны быть сформированы специальным образом
- Ошибка типа `error` **не равна** коду ошибки.
- gRPC Status Code **не равен** коду ошибки.
- Методы-ресиверы `.String()` `.I18N()` у типа `ErrorCode` не являются текстом ошибки
- Коды ошибок на уровне приложения должны иметь четкий диапазон значений привязанный к конкретному приложению
