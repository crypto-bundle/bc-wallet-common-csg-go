# Линтеры. Правила размещения конфигурации для линтеров

---
**Цель**: Настроить утилиты проверки стиля и качества кода
**Категория правил**: Layouts, linting
**Краткое содержание:** Правила и настройки линтеров для проверки стиля кода
---
## Введение

В данном документе описано несколько правил организации файлов с конфигурацией для утилиты `golangci-lint`.

## Правила

Фактически все сводиться к простому:
- Файл конфигурации должен называться `.golangci.yml`
- Файл конфигурации должен быть расположен в корне директории репозитория
- Функционал запуска линтера на локальном окружении должен быть добавлен в виде цели
  в `Makefile`.
