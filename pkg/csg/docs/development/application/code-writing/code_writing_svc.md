# Написание кода. Сервис-компонент

## Введение

Сервис-компонент — это отдельная логическая часть программы, инкапсулирующая конкретную бизнес-логику или задачу. Примеры:

- Структура, скрывающая логику взаимодействия с базой данных с точки связности (подключение, проверка наличия связей, переподключение)
- Структура, скрывающая логику работы с конкретными таблицами базы данных (компиляция SQL-запросов, вызовы SQL-кода, получение и обработка данных)
- Структура, исполняющая бизнес-логику, но скрывающая внутри детали и алгоритмы её реализации
- Структура, реализующая фоновые асинхронные процессы

В проекте определены строгие требования к оформлению сервис-компонентов, их жизненному циклу и порядку передачи зависимостей. Ниже — ссылки на подробные правила.
