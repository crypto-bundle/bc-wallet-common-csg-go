# Правила формирования конфигурации для приложения

---
**Цель**: Определить форму и формат конфигурационных файлов
**Категория правил**: Layouts, конфигурация
**Краткое содержание:** Требования к формату и расположению конфигов приложения
---
## Введение

Конфигурационные файл для целевых приложений могут быть в различных форматах, допустимо использовать следующие:
- [DotEnv файлы](#dotenv-файла)
- [json файлы](#json-файлы)
- [yaml файлы](#yaml-файлы)

## Правила

Основным способ передачи конфигурационных параметров целевому приложению являются `dotenv` файлы.
Именование этих файлов должно быть сформированно в соответсвии с определенными шаблонами, а именно
 
### Dotenv файла

```
env-<application_name>.env
env-<application_name>-<application_purpose>.env
```

Пример - `env-hdwallet-controller-manager-api.env`, здесь `hdwallet-controller` - это название приложения.
А `manager-api` - это цель с которой запущено приложение.

Файлы *.env с конкретными данными для приложения не должны храниться в  git-репозитории, они должны быть созданы только
на локальном компьютере разработчика. В git-репозитории храняться только _"файлы-примеры"_, они же `example` файлы.
Шаблон имени для `example` файлов должен иметь постфикс `-example` в собственном имени файла, но при этом
находиться перед `.env` расширением файла. Ниже представлен шаблон имени файла:

```
env-<application_name>-example.env
env-<application_name>-<application_purpose>-example.env
```

Пример - `env-hdwallet-controller-manager-api-example.env`, здесь `hdwallet-controller` это название приложения.
Следующая часть `manager-api` это цель с которой запущено приложение. И постфикс `-example` указывает,
что файл является примером из которого можно создать целевой `.env` файл.

Логичным будет сказать что e `-example.env` файл внутри себя должен хранить список всех переменных окружения,
которые необходимы целевому приложения для которого `-example.env` файл создан.
Пример такого файла можно посмотреть в [env-hdwallet-controller-manager-api-example.env](./examples/env/env-hdwallet-controller-manager-api-example.env) файле.
